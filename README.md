# Pioneers website

The website for Pioneers, a digital marketing agency with app developers, website designers, email marketers, social media marketers, SEO experts and AI automation experts.

## What's in here

- `index.html`: the whole site (layout, styles and scripts)
- `img/`: logo layers, team photos, case-study screenshots and social posts
- `netlify.toml`: hosting settings for Netlify

## How updates go live

This repository is connected to Netlify. Every change pushed to the `main` branch is published automatically within about a minute. Netlify keeps every past version, so any update can be rolled back from the Deploys tab.

## Contact links

Booking, WhatsApp, email and Upwork links are set in one place, near the bottom of `index.html`, in the `LINKS` block.
